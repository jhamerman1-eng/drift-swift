# Phase 0 — Safety rails first (same day)

**Goal:** be able to turn this on/off and not crash if the sidecar isn’t there.

1. **JIT-JTR-001 Config & toggle**

   * Add keys to `configs/bots/jit.yaml`:

     ```yaml
     jitter_enabled: false
     jitter_backend: ts-sidecar      # ts-sidecar | py-legacy
     jitter_mode: shotgun            # shotgun | sniper
     auction_ignore_swift: true
     ```
   * Orchestrator: on boot and **SIGHUP** re-read; when `jitter_enabled=false`, route to *current Python path*.
   * Done when: flip flag at runtime and we live-switch with no restart; logs show backend/mode.

2. **Rollback path**

   * One env flip `JITTER_ENABLED=0` → live revert to Python JIT.
   * Alert rules (stale params, sidecar down) wired to suggest rollback in the message.

# Phase 1 — Control plane (publisher + sidecar skeleton)

**Goal:** keep alpha/risk in Python; let TS do last-mile fills.

**Goal:** one response per auction, hard caps in the hot path, degrade safely.

5. **JIT-JTR-003 Dedup (Swift vs Auction) + cross-mode arbitration**

   * Turn on SDK’s “ignore Swift in Auction subscriber” flag (if present).
   * Add in-process **DedupeCache** keyed by `market|maker|start_slot|end_slot|nonce` in the sidecar.

   * Metrics: `jit_dedup_seen_total{source}`, `jit_dedup_filtered_total{source}`.
   * Done when: 10k dual-notify replay → **0** double placements.

6. **JIT-JTR-006 Caps & lot size (in TS)**

   * Enforce `minPos/maxPos` per side on every send.
   * Round size to exchange lot; clamp to `clipMaxUnits` (if provided).
   * Gauges: `jit_cap_headroom_long/short`, counter: `cap_violation_attempts_total`.
   * Done when: violation attempts **= 0** and gauges match allocator headroom.

7. **JIT-JTR-007 Staleness**

   * Track `params_age_ms`; **age > 2s** → widen ×1.5, halve clip; **age > 10s** → HALT and surface in `/ready`.
   * Also export `alloc_snapshot_age_ms` from Python publisher.
   * Done when: kill publisher for 5 s → sidecar degrades; >10 s → HALT; recovery resumes normal.

## Tiny code stubs you’ll need (just the shape)

**Python → TS payload (already computed by your JITEngine):**

```python
params = {
  "market": "SOL-PERP",
  "bidBps": round(bid_bps, 2),      # from (microprice, spoof, toxicity)
  "askBps": round(ask_bps, 2),
  "minPos": limits.max_short_abs * -1,
  "maxPos": limits.max_long_abs,
  "clipMaxUnits": clip_max,         # optional
  "subAccountId": profile.sub_account,
  "ts": now_ms,
  "version": "1.0.0"
}
publisher.publish("jit.params.SOL-PERP", params)
```

**TS size/cap check before send:**

```ts
function clamp(size: number, side: "buy"|"sell", ctx: Caps): number {
  const head = side === "buy" ? ctx.maxPos - ctx.currentPos
                              : ctx.currentPos - ctx.minPos;
  const clip = ctx.clipMaxUnits ?? Number.MAX_VALUE;
  const allowed = Math.max(0, Math.min(size, head, clip));
  return roundToLot(allowed, ctx.lotSize);
}
```
